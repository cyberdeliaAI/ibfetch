# Branding assets

The original ibfetch music-note/download-tray artwork is under the project's MIT
license. ibfetch-icon.svg is the editable master; the matching 1024px PNG is used
for native app icons. The app embeds the SVG and needs no external image service.

The two Powered by iBroadcast SVGs are unmodified originals downloaded from the
[official branding page](https://help.ibroadcast.com/en/developer/branding).
iBroadcast's name and marks belong to iBroadcast; they are not relicensed under
ibfetch's MIT license. Their inclusion identifies the service used by this
independent app and does not imply endorsement.

The same exact SVG bytes are embedded as data images in the standalone Python
page, so the app does not contact an external image server. Light/dark appearance
selects the matching official version without altering either logo.
